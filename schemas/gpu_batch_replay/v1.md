# GPU Candidate-Batch Invariant Replay Contract v1

GPU candidate-batch replay v1 is a canonical UTF-8 line record. Fields occur
exactly once in schema order, unknown fields are rejected, and every line ends
with LF. The final `checksum_fnv1a64` field is excluded from the checksum; its
value is Board IR's byte-stable FNV-1a checksum of all preceding bytes. The
referenced fixture has an independent byte checksum.

The artifact fixes the candidate-batch and replay schema versions, fixture,
forced generator, deterministic readback fault, layer, every execution budget,
batch/query correlation identity, and the complete request-local candidate
policy. `banned_resources=none` and `resource_penalties=none` are literal empty
v1 sets; no resource action is inferred. The artifact also pins Board IR,
compiler-profile, compiler-version, rule-bucket, routing-profile, policy, and
DeviceCompiledBoard associations. Reproduction rejects association drift
before executing CUDA.

Schema v1 supports these replay/test-only faults and exact expected invariant
identifiers:

| `fault` | Expected invariant |
|---|---|
| `workspace_bounds` | `gpu.batch.workspace.bounds.v1` |
| `workspace_owner` | `gpu.batch.workspace.owner.v1` |
| `query_telemetry` | `gpu.batch.query.telemetry.v1` |
| `memory_accounting` | `gpu.batch.memory.accounting.v1` |
| `batch_telemetry` | `gpu.batch.telemetry.v1` |
| `query_identity` | `gpu.batch.query.identity.v1` |
| `false_disconnected` | `gpu.disconnected.cpu_reachable.v1` |
| `unauthenticated_cuda_producer` | `candidate.builder.gpu_producer_authentication.v1` |

Readback faults are applied after normal CUDA readback by a replay/test-only
backend decorator. `unauthenticated_cuda_producer` instead uses a no-corruption
wrapper around the real CUDA backend: host route validation must succeed, the
generic wrapper must remain ineligible for the concrete CUDA producer seal, and
candidate construction must return `unsupported` with the exact candidate
invariant. Production route policy, CUDA execution requests, and kernels expose
no fault controls. Every other replay succeeds only when its one immutable
query retains the artifact's batch, query, input-ordinal, and policy
associations and returns `internal_invariant` with the exact expected
identifier. An unrelated failure is not a successful reproduction.

All checked-in GPU batch invariant artifacts are reproduced with one command:

```sh
bazel test --config=cuda //:gpu_batch_replay_test
```

A single artifact can be inspected with:

```sh
bazel run --config=cuda //:gpu_batch_replay -- \
  replays/gpu/batch_workspace_owner_v1.replay
```

Replay remains diagnostic evidence. It neither bypasses exact host validation
nor changes production generation policy.
