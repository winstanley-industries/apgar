# GPU Invariant Replay Contract v1

GPU invariant replay v1 is a canonical UTF-8 line record. NUL and CR bytes are
forbidden. Fields occur exactly once in schema order, unknown fields are
rejected, and every line ends with LF. The final `checksum_fnv1a64` field is
excluded from the checksum; its value is Board IR's byte-stable FNV-1a checksum
of all preceding bytes. The referenced fixture has its own byte checksum.

Every integer field, including both checksums, uses canonical unsigned decimal
with grammar `0|[1-9][0-9]*`. Signs, leading zeroes, whitespace, empty values,
and values outside the field's unsigned integer width are rejected.

APGAR is unreleased, so schema v1 is the current development contract rather
than a compatibility promise. Before the first release, a missing association
field may be added in place only under ADR-009's atomic
producer/consumer/schema/artifact rule. An older development layout is then
unsupported and must be rejected structurally. Incompatible changes after the
first release require a new major schema version.

The widths are schema properties rather than C++ implementation choices:

| Unsigned width | Fields |
| --- | --- |
| 32-bit | `schema_version`, `layer`, `maximum_rounds` |
| 64-bit | `fixture_checksum_fnv1a64`, `expected_board_content_hash`, `expected_profile_fingerprint`, `expected_routing_profile_fingerprint`, `expected_device_view_fingerprint`, `checksum_fnv1a64` |

The artifact fixes the fixture, forced generator, deterministic fault, layer,
round budget, source-board content hash, compiler-profile fingerprint,
`APGAR-ROUTING-PROFILE-V1` fingerprint, DeviceCompiledBoard fingerprint,
expected failure class, and stable invariant identifier. Reproduction rejects
any semantic association drift before launching the kernel. The routing-profile
fingerprint is computed from the CompiledBoard's retained prepared profile; it
therefore authenticates routed-net identity without reinterpreting the legacy
numeric-rule scalar. APGAR evolves this V1 contract in place until its first
public compatibility boundary; V1 artifacts lacking
`expected_routing_profile_fingerprint` are rejected rather than migrated.
Schema v1 supports the Phase 2
`goal_predecessor_self_cycle` fault and expects the host's untrusted-result
validator to return `internal_invariant` with invariant identifier
`gpu.predecessor.self_reference.v1`; an unrelated internal error is not a
successful reproduction. The fault is applied by a replay/test-only backend
decorator after normal device readback. Production route policy, backend
execution requests, and CUDA kernels contain no fault-injection controls.

`goal_predecessor_self_cycle_v1.replay` is the canonical reproducible artifact.
`goal_predecessor_self_cycle_wrong_routing_profile_v1.replay` is a
checksum-valid but deliberately unbindable negative artifact: it differs only
in the expected routing-profile fingerprint and must be rejected before a
backend is constructed. It is evidence for the association gate, not an
alternate replay authority. With no explicit artifact argument, `gpu_replay`
checks that negative first and then reproduces the canonical artifact.

The checked-in artifact is reproduced on a CUDA host with one command:

```sh
bazel run --config=cuda //:gpu_replay
```

Replay is diagnostic evidence, not a legality bypass. The normal exact
reconstruction validator remains active.
