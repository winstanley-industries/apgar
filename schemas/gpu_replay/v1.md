# GPU Invariant Replay Contract v1

GPU invariant replay v1 is a canonical UTF-8 line record. NUL and CR bytes are
forbidden. Fields occur exactly once in schema order, unknown fields are
rejected, and every line ends with LF. The final `checksum_fnv1a64` field is
excluded from the checksum; its value is Board IR's byte-stable FNV-1a checksum
of all preceding bytes. The referenced fixture has its own byte checksum.

Every integer field, including both checksums, uses canonical unsigned decimal
with grammar `0|[1-9][0-9]*`. Signs, leading zeroes, whitespace, empty values,
and values outside the field's unsigned integer width are rejected.

The widths are schema properties rather than C++ implementation choices:

| Unsigned width | Fields |
| --- | --- |
| 32-bit | `schema_version`, `layer`, `maximum_rounds` |
| 64-bit | `fixture_checksum_fnv1a64`, `expected_board_content_hash`, `expected_profile_fingerprint`, `expected_device_view_fingerprint`, `checksum_fnv1a64` |

The artifact fixes the fixture, forced generator, deterministic fault, layer,
round budget, source-board content hash, compiler-profile fingerprint,
DeviceCompiledBoard fingerprint, expected failure class, and stable invariant
identifier. Reproduction rejects any semantic association drift before
launching the kernel. Schema v1 supports the Phase 2
`goal_predecessor_self_cycle` fault and expects the host's untrusted-result
validator to return `internal_invariant` with invariant identifier
`gpu.predecessor.self_reference.v1`; an unrelated internal error is not a
successful reproduction. The fault is applied by a replay/test-only backend
decorator after normal device readback. Production route policy, backend
execution requests, and CUDA kernels contain no fault-injection controls.

The checked-in artifact is reproduced on a CUDA host with one command:

```sh
bazel run --config=cuda //:gpu_replay
```

Replay is diagnostic evidence, not a legality bypass. The normal exact
reconstruction validator remains active.
