# GPU Invariant Replay Contract v1

GPU invariant replay v1 is a canonical UTF-8 line record. Fields occur exactly
once in schema order, unknown fields are rejected, and every line ends with
LF. The final `checksum_fnv1a64` field is excluded from the checksum; its value
is Board IR's byte-stable FNV-1a checksum of all preceding bytes. The referenced
fixture has its own byte checksum.

The artifact fixes the fixture, forced generator, deterministic fault, layer,
round budget, source-board content hash, compiler-profile fingerprint,
DeviceCompiledBoard fingerprint, and expected failure class. Reproduction
rejects any semantic association drift before launching the kernel. Schema v1
supports the Phase 2 `goal_predecessor_self_cycle` fault and expects the host's
untrusted-result validator to return `internal_invariant`.

The checked-in artifact is reproduced on a CUDA host with one command:

```sh
bazel run --config=cuda //:gpu_replay
```

Replay is diagnostic evidence, not a legality bypass. The normal exact
reconstruction validator remains active.
